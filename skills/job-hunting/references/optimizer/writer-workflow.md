# Resume Writer 工作说明

GM 写简历时按本页工作。入口为 [optimizer/SKILL.md](../../optimizer/SKILL.md)。事实只来自材料表里的 md 与原始简历。

## 准备

1. 确认本次岗位与选定模式；模式缺失时按入口三选一提问，等待回答。可先读文件、盘点结构，不先写正文或改版式。
2. 通读完整原简历或目标模板：所有页、页首信息、章节、主要经历和固定元素；列出章节与条目的去向清单。原件不可读、模板缺源文件或只有 PDF 时，说明范围与保真局限。
3. 读取该岗位的 JD 全文与材料 md；摘要不能冒充 JD 全文。写作前读取当前招呼语表达记忆，记下所用版本。

## 内部草稿迭代

先按 JD 需求组织材料里的事实，再写出完整简历的内部稿。

- 材料里有的内容：优化措辞、重点与相关性；保留准确的职责、时间与指标归属。
- 材料里没有的：不写；需要本人补充时，在对话里问，答案先由 GM 整理进材料 md。
- 歧义、矛盾或无依据的数字：收窄或删掉受影响的句子，继续处理其他内容；不估算数字。
- 风格、重复、长度或关键词问题：按影响继续改写；没有指标时写范围与产出。

每轮检查全原件去向：保留、改写或有理由删减。未改写的内容照样保留，片段必须合回完整简历；目标模板的槽位无事实可填时如实留空并说明，不造内容填满。

结束条件：问题已处理，或需要本人补充，或宿主中断。后两种保留内部稿与恢复点。

## 交付

按模式制作完整文档。保留原结构或模板填充时逐页对照；新版式按本人选定方案检查。渲染后对实际 PDF 运行 `jobagent harness check-pdf`（或直接用 `jobagent harness render`），清理内部备注与批注，再放进岗位表的 `简历cv（PDF）`，并把 `批准状态` 写为 `待你批准`。

表达质量可按需用 [写作方法](writing-methods.md) 自查；模拟读者意见不能冒充真人看法。发送、投递和在线简历修改不在此角色权限内。
