# 停止条件

全流程中需要停下来交给人的时刻集中在这里。停止不是失败;继续推进才是。

## 必须停止并等待人的情形

| 触发 | 处理 |
|---|---|
| 飞书或钉钉 CLI 未安装或未授权 | 停止;告诉本人如何安装与授权 |
| 缺私有设置（角色、执行方式、搜索间隔与数量） | 停在相关步骤;回到 Initial Setup,不自己定默认值 |
| 材料里没有支撑某条主张的事实 | 不写这条;需要时在对话里问本人,答案先整理进材料 md |
| 质量门禁任一项未达标 | 不交付该稿 |
| `jobagent harness check-pdf` 未通过(抽取顺序错乱、超页、带内部批注) | 不交付,先修排版 |
| `批准状态` 不是 `已批准` | EM 不执行外发 |
| 平台要求登录、验证码或其他人工操作 | 停止;由本人在平台上完成后,再显式发起下一次 |
| 外发结果不明 | 先去平台核实,不重复发送 |

## 不构成重试理由的状态

登录、CAPTCHA、验证、风控与平台变更**不是**瞬时故障。不要自动重试,不要更换账号或代理绕开,不要降低请求间隔试探。这些状态一律翻译为 `USER_INTERVENTION_REQUIRED` 并交还控制权。

只有提供方明确声明为暂时性的传输故障才可以重试,且最多一次。结构化输出格式错误可以尝试一次修复。

## 停止时要输出什么

停止时给出:触发了哪一条停止条件、当前已完成到哪一步、恢复需要人做什么、以及恢复后从哪个能力继续。不要在停止的同时抛弃已经通过校验的中间产物。
