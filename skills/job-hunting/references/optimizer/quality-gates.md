# 优化器质量门禁

GM 交付简历前逐条自查。门禁是 GM 的判断，不是代码校验；代码只核对 PDF 文字与最终正文一致（`jobagent harness check-pdf`）。

```text
材料里没有依据的主张 = 0
材料里没有依据的数字 = 0
与材料相矛盾的主张 = 0
语义夸大 = 0
每一条实质性主张都能指回材料 md 或原始简历的具体位置
```

任一项不达标，不交付该稿。行文再流畅，也不能让一条没有依据的主张通过。关键词或 ATS 目标绝不凌驾于事实接地之上。

写错的地方由本人在 `批准状态` 驳回或直接修改，trace 进入 Dream，由 GM 查证后写入 Memory，必要时修正材料 md。自查不替本人批准，也不要求本人逐条确认材料。

## 负面清单：自证式表述

简历句子写做了什么、产出了什么，不替本人下评语。下列写法一律判为语义夸大，要求删改：

- 断言自身能力或价值：“沉淀了……能力”“具备……能力”“练就了……”；
- 自评熟练度：“熟练”“精通”“深度使用者”；
- 替经历下结论：“这段经验是……的直接来源”“为……打下基础”；
- 没有数字的效果断言：“有效提升”“显著改善”。材料里有数字就写数字，没有就不写。

即使材料原文含这类措辞，改写时也要去掉，只保留可核对的动作与结果。本人明确要求保留的个别表述可作为例外，但仍须在材料里有依据。
